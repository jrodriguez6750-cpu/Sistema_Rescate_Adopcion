
# 🐾 Sistema Web de Control de Rescate y Adopción

## Descripción del proyecto

Huellitas de Esperanza es un prototipo estructural web desarrollado para representar un sistema de control de rescate y adopción de animales.

El proyecto permite organizar la información del refugio, registrar los datos de animales rescatados y consultar los casos registrados.

## Objetivo

Implementar la estructura fundamental de un sistema web utilizando HTML5 y etiquetas semánticas, facilitando la organización y navegación de la información.

## Tecnologías utilizadas

- HTML5
- Visual Studio Code
- Google Chrome
- GitHub

## Estructura del proyecto

- index.html: Página principal y resumen del refugio.
- reportar.html: Formulario de ingreso de animales rescatados.
- rescates.html: Listado de animales registrados.
- README.md: Documentación del proyecto.
- assets/img: Carpeta destinada a imágenes.

## Descripción de las páginas

### Página principal
Presenta la bienvenida, información y resumen del refugio.

### Reportar rescate
Contiene un formulario para ingresar los datos de un animal rescatado, su categoría, urgencia médica y descripción.

### Ver rescates
Presenta una tabla organizada con los casos registrados.
